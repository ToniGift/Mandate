Mandate

A control desk between an AI agent and PayPal. The agent asks, fixed rules decide, and a person signs off on anything held.

Good to know

  • Payments run on the PayPal sandbox, so no real money moves.
  • Decisions come from rules written in code, not from an AI model.
  • Every request is written to the audit trail.
